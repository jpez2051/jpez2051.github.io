# Action 4 Animals Hawaii branding

Website reference: https://www.action4animalshawaii.com/ (inspected October 29, 2026).
Original logo source: https://static.wixstatic.com/media/520281_dbeef667280944c488b5db2c63f5a36a~mv2.png
App asset: public/rescue-logo.png; deployed as kitten-care/rescue-logo.png. Original 720 x 720 artwork is unchanged and displayed proportionally with clear space.

Selected Option C uses website colors #1C1D74 (navy), #5A52B8 (violet), and #E5EBFA (pale blue), with derived neutrals. Pink is a restrained interpretation of the logo accent rather than an official brand-guide specification. The logo appears in the desktop sidebar and phone header, favicon and install manifest, and is cached for offline reopening.

Feature icons use original SVG paths in src/components/Icon.tsx, with text labels retained. No external icon font, image service or new runtime dependency was added. Medication and care-history domain rules are unchanged by this visual release.
